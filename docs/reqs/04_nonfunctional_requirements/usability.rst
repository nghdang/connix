Usability
=========

.. sw-req:: Usability Consistency Between Interfaces
    :id: [$SW_REQ_NF USABILITY_CONSISTENCY_BETWEEN_INTERFACES]
    :desc: For each capability exposed by both interfaces with the same input
           configuration, Connix SHALL make GUI and equivalent CLI invocations
           perform the same action and produce the same result.

.. sw-req:: Usability Consistency Between Interfaces GUI Action Parity
    :id: [$SW_REQ_NF USABILITY_CONSISTENCY_BETWEEN_INTERFACES_GUI_ACTION_PARITY]
    :desc: Connix SHALL make its GUI perform the same underlying action as an
           equivalent CLI invocation for each capability exposed by both
           interfaces with the same input configuration.

.. sw-req:: Usability Consistency Between Interfaces GUI Result Parity
    :id: [$SW_REQ_NF USABILITY_CONSISTENCY_BETWEEN_INTERFACES_GUI_RESULT_PARITY]
    :desc: Connix SHALL make its GUI produce the same result as an equivalent CLI
           invocation for each capability exposed by both interfaces.
