Assumptions
===========

This section lists facts assumed to be true for the duration of the
project. The requirements depend on these assumptions. If any assumption
proves false, the affected requirements must be reviewed and updated.

Development Environment
------------------------

- Users have access to a development workstation on which a compiler,
  CMake, and Conan v2 can be installed without administrator or IT
  approval friction.
- A C++20-conforming compiler (GCC 11+ or MSVC 2022) is available on
  every development machine.

Project Organization
---------------------

- The project is maintained by a single author. Project pace and scope
  assume single-maintainer capacity, not a team.
- There is no legacy codebase to migrate. All code, documentation, and
  configuration is written from scratch.
- Contributions from the open-source community are possible but not
  required for the project to succeed.
