Constraints
###########

.. list-table::
   :header-rows: 1

   * - No.
     - Name
     - Constraint
   * - 1
     - Platform
     - Connix shall be able to run on both Windows and Linux. On windows, the tool will not support
       Unix Domain Socket protocol.
   * - 2
     - Programming language
     - Connix shall be developed by modern C++ (C++17).
   * - 3
     - GUI Framework
     - Connix GUI shall be developed by Qt/QML framework.
